# islamkwt

عدّاد طلبات خدمة «علمني الإسلام»، صفحة ثابتة تُنشر على GitHub Pages على النطاق الموجود في ملف `CNAME`.

- `index.html`: صفحة العدّاد.
- `stats.json`: الأرقام المعروضة (تُحدَّث بأدوات المجلد `tools/`).
- المفتاح الظاهر في الصفحة هو مفتاح anon العام لـ Supabase وهو مصمّم ليكون علنيًا، وتحميه سياسات RLS في قاعدة البيانات.
